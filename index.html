CASE NO. 01 · DATA SCIENCE CAPSTONE

Flood Risk Prediction from BMKG Weather Data

Dataset, feature selection & modeling led by the writer

FloodGuard is a machine learning project that predicts flood risk using historical BMKG weather data. The project applies data preparation, feature selection, and predictive modeling to transform meteorological patterns into an accessible flood-risk indicator through a Streamlit application.

CASE NO. 02 · MACHINE LEARNING EXPERIMENT

RAG OpenSearch Hospital Chatbot

Presented in Bahasa Indonesia for an executive audience

A Retrieval-Augmented Generation (RAG) chatbot that uses OpenSearch for semantic document retrieval and an LLM to provide accurate, context-grounded responses to hospital-related queries. The system combines vector embeddings, KNN search, and document retrieval.
